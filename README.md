# Battle Cats Fabric

A small fan-made Minecraft 1.20.1 Fabric mod inspired by the playful battle-cat theme. It adds a Cat Bell item with a cooldown-friendly utility effect and is intentionally asset-free so it can be expanded with original models and textures.

## Build

Use the **Actions** tab and run **Build mod jar**, then download the `battle-cats-fabric-jar` artifact from the completed workflow.

## Install

Install Fabric Loader for Minecraft 1.20.1 and place the downloaded jar in `.minecraft/mods` alongside Fabric API.

This is an unofficial fan project and is not affiliated with PONOS or The Battle Cats.
